# 算法核心题清单

## 题目

算法面试最值得优先刷哪些模式？

## 一句话回答

优先刷能覆盖大多数高频题的模式：滑窗、双指针、二分、DFS/BFS、回溯、堆、并查集、动态规划。

## 展开回答

### 第一优先级：模板化掌握

- 最长无重复子串
- 最小覆盖子串
- 两数之和 / 三数之和
- 二分查找与二分答案
- 二叉树层序遍历
- 二叉树路径和
- 岛屿数量
- 全排列 / 子集
- top k 问题
- 合并 k 个有序链表
- 并查集连通性问题
- 爬楼梯 / 打家劫舍 / 最长递增子序列

### 第二优先级：表达要求

- 每道题必须先说题型
- 必须说出状态或不变量
- 必须说复杂度
- 必须说边界条件

## 面试官追问

- 为什么这题想到滑窗？
- 为什么这题不是贪心？
- DFS 和 BFS 怎么选？

## 易错点

- 代码会写，思路讲不清
- DP 状态定义不清
- 忽略初始化和边界条件
