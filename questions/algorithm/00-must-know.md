# 算法核心题清单

## 题目

算法面试最值得优先刷哪些模式，顺序应该怎么排？

## 一句话回答

优先刷覆盖面最大的模式：`滑动窗口 -> 双指针 -> 二分 -> 树/图搜索 -> 回溯 -> 堆与并查集 -> DP`。顺序上先练模式识别，再练口述，再练边界和变体。

## 展开回答

### 第一层：必须拿下的高频模式

这部分是算法面试的主干：

- 滑动窗口：最长无重复子串、最小覆盖子串
- 双指针：两数之和、三数之和、盛最多水的容器
- 二分：查找、边界查找、二分答案
- 二叉树：层序遍历、最近公共祖先、路径和
- 图搜索：岛屿数量、课程表、最短路径基础
- 回溯：全排列、子集、组合总和
- 堆：top k、合并 k 个有序链表
- 并查集：连通性、冗余连接
- DP：爬楼梯、打家劫舍、最长递增子序列、背包

### 第二层：每类模式都要会说什么

每做一题，都要先回答这几个问题：

- 这题属于什么模式
- 为什么这个模式适合
- 核心不变量或状态是什么
- 时间复杂度和空间复杂度是什么
- 边界条件有哪些

### 第三层：建议刷题顺序

1. 先看 [算法专题首页](../../docs/topics/algorithm/00-index.md)
2. 再看 [算法方法论](../../docs/topics/algorithm/01-algorithm-methodology.md)
3. 再看 [高频模式](../../docs/topics/algorithm/02-common-patterns.md)
4. 再看 [框架、例题和训练法](../../docs/topics/algorithm/03-frameworks-and-drills.md)
5. 然后刷 [算法高频题](high-frequency.md)
6. 最后刷 [模式与 DP](patterns-and-dp.md)

### 第四层：最小交付标准

每个模式至少要做到：

- 能举出 `2` 道代表题
- 能口述 `1` 份模板思路
- 能指出 `2` 个常见坑
- 能讲出 `1` 个面试官追问

### 1 分钟速答表

| 模式 | 最低合格回答 |
| --- | --- |
| 滑动窗口 | 适合连续区间问题，关键是窗口状态能增量维护，并且不合法时能靠左指针收缩恢复。 |
| 双指针 | 适合利用顺序性或相向逼近来减少枚举，核心是指针移动必须有明确依据。 |
| 二分 | 不是只会查数字，而是找到有单调性的答案空间，再通过边界收缩逼近结果。 |
| DFS / BFS | DFS 更适合递归结构和回溯，BFS 更适合最短层数和分层遍历，关键看信息流方向。 |
| 回溯 | 本质是枚举解空间并在过程中剪枝，重点不是递归模板本身，而是状态恢复和剪枝条件。 |
| 堆 | 适合随时维护 top k 或当前最值，核心是把“全量排序”降成“局部维护”。 |
| 并查集 | 适合连通性和集合合并问题，路径压缩和按秩合并让复杂度接近常数。 |
| 动态规划 | 关键不是背公式，而是先定义状态、转移和初始化，再谈遍历顺序和空间优化。 |
| 二叉树 | 先判断信息是自顶向下还是自底向上，再决定前序、后序还是层序。 |
| 图搜索 | 先判断是连通性、拓扑关系还是最短路，再选 DFS、BFS、拓扑排序或并查集。 |

### 最小合格回答标准

如果你只想把算法先答到不失分，至少做到：

- 不先写代码，先说这题属于什么模式
- 能说清核心不变量、状态或单调性
- 能主动补一个边界条件和一个常见坑
- 被追问时至少能继续讲 `为什么不是别的模式 / 复杂度 / 变体怎么改`

## 面试官追问

- 为什么这题想到滑窗而不是哈希暴力？
- 为什么这题不是贪心？
- DFS 和 BFS 怎么选？
- DP 的状态为什么这么定义？
- 如何把这题从暴力优化到线性或对数复杂度？

## 易错点

- 代码会写，但思路讲不清
- DP 状态定义不清
- 忽略初始化和边界条件
- 看到变体题就脱离原有模式
