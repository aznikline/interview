# 后端核心题清单

## 题目

后端面试最应该优先刷哪些题？

## 一句话回答

先刷能串成完整链路的核心题：数据库、缓存、MQ、一致性、高并发、分布式锁、限流降级、项目表达。

## 展开回答

### 第一优先级：必须会讲

- MySQL 为什么用 B+ 树？
- MVCC 解决了什么？
- 索引失效有哪些典型场景？
- 可重复读为什么还能防幻读？
- Redis 为什么快？边界在哪里？
- 缓存穿透、击穿、雪崩如何治理？
- 更新数据库后为什么通常删缓存？
- MQ 如何保证消息不丢？
- 至少一次为什么会导致重复消费？
- 幂等如何落地？
- 分布式锁为什么经常不是最优解？
- 如何做限流、熔断、降级？
- 如何设计高并发下单 / 秒杀链路？
- 讲一个你做过的高并发或稳定性项目

### 第二优先级：必须会追问

- redo log / undo log / binlog 区别
- 行锁、间隙锁、next-key lock 的区别
- 热 key 和大 key 怎么处理
- 消息积压如何排查和止血
- 时钟回拨为什么会影响分布式 ID
- 为什么说一致性没有银弹

## 面试官追问

- 如果面试只给你 30 分钟准备，你会先讲哪 5 个？
- 如果项目不强，怎么靠这些题稳住一面？
- 哪些题最适合连到系统设计？

## 易错点

- 只会背组件，不会讲链路
- 只会讲 happy path，不会讲故障与补偿
- 只会说“项目很复杂”，说不出指标
