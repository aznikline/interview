# 操作系统高频题

## 题目

进程和线程的本质区别是什么？

## 一句话回答

进程是资源分配单位，线程是 CPU 调度单位；线程共享进程地址空间，而进程之间默认隔离。

## 展开回答

- 进程拥有独立虚拟地址空间、文件描述符表等资源上下文
- 同一进程内线程共享代码段、堆和全局变量，但各自有独立栈和寄存器上下文
- 线程切换开销通常小于进程切换，但同步复杂度更高
- 在服务端场景中，线程模型影响吞吐、延迟和编程复杂度

## 题目

select、poll、epoll 的区别是什么？

## 一句话回答

三者都是 I/O 多路复用机制，但 epoll 在大量连接场景下更高效，因为它避免了每次线性扫描所有 fd。

## 展开回答

- select 用位图表示 fd 集合，fd 数量受限
- poll 用数组，无固定上限，但仍需要每次遍历
- epoll 把“关注列表”和“就绪列表”拆开，事件驱动返回就绪 fd
- epoll 更适合海量长连接，但业务处理仍可能成为瓶颈

## 题目

为什么会发生死锁？怎么避免？

## 一句话回答

死锁产生于互斥、占有并等待、不可剥夺、循环等待四个条件同时成立，避免思路是破坏其中至少一个条件。

## 展开回答

- 最常见做法是统一加锁顺序，破坏循环等待
- 使用 try lock 或超时避免长期占有
- 减小锁粒度，缩短临界区时间
- 某些场景下用无锁结构或消息传递规避共享状态
