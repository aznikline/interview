# 校招路线

适合：

- 校招、转码、基础不够稳但需要尽快形成面试主线
- 题目覆盖和表达稳定性优先于深度专题
- 想先拿到面试及格线，再补更深的系统和基础设施内容

## 核心特点

- 高频题覆盖优先于深度专题
- 算法权重更高
- 项目表达要突出“你做了什么”和“为什么这么做”

## 优先顺序

算法 > 八股 > 项目表达 > 基础系统设计

## 校招最容易失分的地方

- 算法会写不会讲
- 八股零散，讲不成链路
- 项目回答过于空泛
- 系统设计只会说“加缓存、加 MQ”
