# OS 14 天计划

适合：

- 已经看过基础 OS 内容，但解释性能现象还不稳定
- 想在两周内把 OS 题从“课本定义”练到“后端性能解释器”
- 目标是看到系统现象能迅速挂到对应机制上

## 使用原则

- 每天只抓 `1` 个场景
- 每天至少完成：`看机制 -> 讲现象 -> 讲指标 -> 讲缓解`
- 不要求推公式，但必须把机制和服务现象连上

## Day 1：进程、线程与调度

- 练进程 / 线程区别、用户态 / 内核态、调度

输出：

- 说清线程切换为什么贵

## Day 2：上下文切换与吞吐

- 练保存恢复上下文、cache/TLB 抖动

输出：

- 说清为什么线程过多反而掉吞吐

## Day 3：虚拟内存

- 练地址空间、页表、按需分配

输出：

- 说清虚拟内存为什么既有价值又有代价

## Day 4：page fault 与尾延迟

- 练缺页、换页、尾延迟

输出：

- 说清为什么 page fault 会放大 P99

## Day 5：I/O 模型

- 练阻塞 / 非阻塞、同步 / 异步、多路复用

输出：

- 说清为什么高并发服务会用多路复用

## Day 6：epoll 与慢请求

- 练 select / poll / epoll、慢连接、线程模型

输出：

- 说清为什么 epoll 不是银弹

## Day 7：零拷贝

- 练 sendfile、mmap、DMA、协议加工

输出：

- 说清减少了什么，没减少什么

## Day 8：锁竞争

- 练死锁、互斥、竞争、阻塞唤醒

输出：

- 说清锁竞争怎么让 CPU 忙但吞吐低

## Day 9：false sharing

- 练 cache line、一致性同步、padding

输出：

- 说清 false sharing 和锁竞争的区别

## Day 10：内存屏障与内存序

- 练重排序、可见性、原子操作

输出：

- 说清内存屏障为什么重要

## Day 11：观测与排障

- 练上下文切换、CPU、页缺失、尾延迟这几类指标

输出：

- 说清先看什么，再怀疑哪层

## Day 12：和后端联动

- 把 OS 问题挂到网络服务、慢请求、MQ、缓存更新

输出：

- 至少 `3` 个“机制 -> 工程现象”例子

## Day 13：和 AI Infra 联动

- 把内存带宽、调度、I/O、线程模型挂到 runtime 和推理服务

输出：

- 至少 `2` 个“OS -> AI Infra”例子

## Day 14：压测与复盘

- 跑 [OS 压测包](../../practice/drills/os-pressure-pack.md)
- 回看 [操作系统代表题清单](../../questions/operating-system/representative-scenarios.md)

输出：

- 一页纸 OS 弱项清单

## 最小验收标准

- 至少 `8-10` 个 OS 核心问题能稳定先给结论
- 至少 `5` 个系统现象能挂到对应机制
- 被追问时能说出指标、代价和缓解方式
