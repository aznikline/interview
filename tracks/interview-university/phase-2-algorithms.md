# Phase 2: Algorithms And Data Structures

这个阶段解决的问题不是“刷题数量”，而是“模式识别和输出稳定性”。

## 阶段目标

- 看到题能快速识别模式
- 写代码前能先说思路
- 复杂度、边界条件和常见坑不再漏

## 建议时长

- 标准版：`10-14 天`
- 压缩版：`5-7 天`

## 这阶段必须拿下的模式

- 滑动窗口
- 双指针
- 二分
- 二叉树 DFS/BFS
- 图搜索
- 回溯
- 堆
- 并查集
- 动态规划

## 每周输出要求

### 输出 1：模式口述

对每种模式至少做一次 `适用场景 -> 核心不变量/状态 -> 代表题 -> 常见坑` 的口述。

### 输出 2：白板表达

至少完成 `10-15` 道中等题的口述表达，不要求全写完，但必须说清：

- 为什么想到这个模式
- 复杂度是多少
- 边界条件是什么

### 输出 3：弱项分类

把你的算法问题按这几类分：

- 模式识别慢
- 代码实现慢
- DP 状态不稳
- 边界条件容易漏

## 退出条件

- 至少 `5` 种高频模式能稳定口述
- 中等难度题不再只靠“题感碰运气”
- 写代码前能先说结构，不再边写边想

## 这个阶段最容易失败的方式

- 只背模板，不理解为什么适用
- 只在编辑器里做题，不练口述
- 看到变体题就和旧模式脱节
- DP 只会背答案，不会推导状态
