# 30 天冲刺计划

## 目标

用 30 天把后端面试能力拉到“能稳定回答高频题、能做基础系统设计、能完成中等算法题”的水平。

## 第 1 周：后端与 OS 打底

- Day 1: MySQL 索引、事务、锁
- Day 2: Redis 数据结构、持久化、缓存问题
- Day 3: MQ、幂等、顺序、重试
- Day 4: 进程线程、上下文切换、锁
- Day 5: select/poll/epoll、零拷贝、mmap
- Day 6: 输出练习 + mock
- Day 7: 周复盘

## 第 2 周：算法高频模板

- Day 8: 双指针、滑窗、前缀和
- Day 9: 链表、栈、队列、堆
- Day 10: 二叉树 DFS/BFS
- Day 11: 图、回溯
- Day 12: 二分与并查集
- Day 13: DP 基础
- Day 14: 周复盘

## 第 3 周：系统设计

- Day 15: 短链
- Day 16: 秒杀
- Day 17: 消息队列
- Day 18: Feed 流
- Day 19: 分布式 ID 与一致性
- Day 20: 项目表达
- Day 21: 周复盘

## 第 4 周：AI 编译器与综合演练

- Day 22: MLIR / XLA / TVM / Triton 关系
- Day 23: 算子融合与 layout
- Day 24: 动态 shape 与 runtime 协同
- Day 25: LLM 推理链路
- Day 26: 综合 mock 1
- Day 27: 综合 mock 2

- Day 29: 题单回顾
- Day 30: 全链路模拟
