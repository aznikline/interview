# 60 天长期计划

这个版本适合两类人：

- 基础还不稳，希望系统补齐的人
- 想按课程节奏完整走一轮，而不是只做冲刺的人

## 总体原则

- 前 40 天解决“体系化输入”
- 后 20 天解决“输出和面试表现”
- 每周至少 `1` 次 mock
- 每周至少 `1` 次复盘

## Week 1-2：后端主链路

- MySQL、事务、锁、MVCC
- Redis、缓存一致性、热 key
- MQ、可靠性、幂等、积压处理
- 项目里的高并发链路回顾

每周输出：

- `5-8` 个后端高频题答案
- `1` 次后端 mock

## Week 3-4：算法与数据结构

- 滑动窗口、双指针、二分
- 树、图、DFS/BFS、回溯
- 堆、单调栈、并查集
- DP 框架

每周输出：

- `10-15` 道中等题口述
- `1` 份算法弱项分类表

## Week 5：操作系统与并发

- 进程线程、调度、上下文切换
- 虚拟内存、缺页、mmap、零拷贝
- 多路复用、epoll、网络 I/O
- 锁、内存屏障、false sharing

每周输出：

- `8-10` 个 OS 高频题答案
- `1` 次“性能问题归因”口述

## Week 6-7：系统设计

- 拆题、估算、数据模型
- 缓存、异步化、高并发
- 秒杀、短链接、Feed、消息系统
- trade-off 与故障处理

每周输出：

- `2` 道完整系统设计题
- `1` 次系统设计 mock

## Week 8：AI 编译器与最终收口

- IR、lowering、fusion、layout、runtime
- LLM 推理链路与指标
- AI 编译器项目表达
- 综合 mock 和总复盘

每周输出：

- `5` 个 AI 编译器 1 分钟回答
- `1` 次 AI Infra mock
- `1` 份最终弱项清单
