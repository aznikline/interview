# 算法模式 14 天计划

适合：

- 已经有一点刷题基础，但模式体系不稳
- 想借你本地 `labuladong` 题单结构做一次高密度算法冲刺
- 目标是在两周内把“会做题”推进到“会识别模式、会口述、会接追问”

## 使用原则

- 每天只抓 `1-2` 个模式，不要贪多
- 每天至少完成：`看模式 -> 口述速答 -> 做代表题 -> 复盘边界`
- 如果时间有限，优先保住前 `10` 天内容

## Day 1：数组双指针

- 看 [算法核心题清单](../../questions/algorithm/00-must-know.md)
- 练两端夹逼、快慢指针、原地去重
- 代表题：两数之和、三数之和、移除重复元素

输出：

- 说清双指针为什么能减少枚举

## Day 2：滑动窗口

- 看 [算法模式地图](../../docs/topics/algorithm/05-labuladong-pattern-map.md)
- 练最小覆盖子串、无重复最长子串
- 补窗口合法性和收缩条件

输出：

- 说清滑窗和双指针的边界

## Day 3：二分搜索

- 练标准二分、左边界、右边界、二分答案
- 补单调性判断

输出：

- 说清二分搜索和二分答案的差别

## Day 4：前缀和 / 差分

- 练区间和、子数组和、批量区间更新
- 补前缀和和哈希表的组合

输出：

- 说清什么时候是前缀和，什么时候是滑窗

## Day 5：栈、队列、单调栈

- 练括号、下一个更大元素、单调结构
- 补为什么能做到线性复杂度

输出：

- 说清单调栈维护的是什么不变量

## Day 6：二叉树遍历

- 练前序、后序、层序
- 补“信息流方向决定遍历方式”

输出：

- 说清路径类、深度类、层级类题怎么选遍历

## Day 7：二叉树分解 / BST

- 练 LCA、验证 BST、BST 删除/搜索
- 补 BST 有序性的利用

输出：

- 说清普通树题和 BST 题的思维差异

## Day 8：图遍历 / 并查集

- 练岛屿数量、课程表、冗余连接
- 补连通性和拓扑思维

输出：

- 说清什么时候 DFS/BFS，什么时候并查集

## Day 9：BFS

- 说清 BFS 为什么天然适合最短步数

## Day 10：DFS / 回溯

- 说清回溯和 DFS 的关系

## Day 13：贪心 / 分治 / 数学

## 最小验收标准

- 至少 `10` 个模式能稳定识别
