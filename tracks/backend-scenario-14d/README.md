# 后端场景 14 天计划

适合：

- 已经有一点后端基础，但知识点之间还是散的
- 想用两周把后端主链路和高频故障题讲顺
- 目标是“看到场景能定位到 DB / Cache / MQ / 一致性 / 恢复”

## 使用原则

- 每天抓 `1` 个核心场景，不要平铺
- 每天至少完成：`看专题 -> 讲 1 分钟答法 -> 过代表题 -> 复盘追问`
- 如果只有一周时间，优先跑前 `10` 天
