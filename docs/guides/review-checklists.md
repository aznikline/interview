# 复习检查清单

## 通用后端

- 能解释 MySQL 索引、事务、MVCC、锁
- 能解释 Redis 快的原因和缓存一致性边界
- 能解释 MQ 的可靠性、顺序性和幂等
- 能讲一个高并发或稳定性治理项目

## 算法

- 能口述滑窗、DFS/BFS、二分、DP、并查集模板
- 能先说思路再写代码
- 能讲复杂度和边界条件

## 系统设计

- 能完成需求澄清
- 能做 1 分钟容量估算
- 能解释关键 trade-off
- 能把设计落到真实业务约束

## 操作系统

- 能说清进程线程、调度、锁、内存、I/O
- 能把 OS 概念映射到后端性能问题

## AI 编译器

- 能讲清 IR、lowering、fusion、runtime boundary
- 能比较 MLIR、XLA、TVM、Triton
- 能解释动态 shape、layout 和性能指标
