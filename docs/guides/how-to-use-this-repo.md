# 如何使用这个仓库

## 如果你是 30 天冲刺

- 先看 [30 天计划](/Users/wizout/op/interview/tracks/sprint-30d/README.md)
- 每天 1 个 topic + 1 份 question set + 1 轮 mock
- 每周做一次复盘，记录不会讲、讲不深、不会延展的点

## 如果你是长期积累

- 先过 roadmap
- 再按 topic 精读
- 每学完一个主题，用对应 questions 做输出
- 遇到项目问题，直接回到 projects 里的案例模板

## 如果你是 AI Infra 方向

- 后端、OS、系统设计不能跳过
- AI 编译器只是在通用基础上拉开的差异化壁垒
- 推荐路径：后端 -> OS -> 系统设计 -> AI 编译器 -> mock
