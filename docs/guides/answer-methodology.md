# 面试回答方法论

## 标准四段式

1. `先给结论`
一句话回答问题，防止说半天没有主旨。

2. `再讲机制`
解释为什么，给出底层原理或系统行为。

3. `补适用场景`
说明什么时候用、什么时候不用。

4. `留一个可追问点`
主动暴露一个你熟悉的深挖方向，把节奏拉到自己擅长的区域。

## 1 分钟回答模板

```text
这个问题我会先分成 A、B、C 三层来看。
结论上，X 更适合 Y 场景，因为它在 Z 方面更稳定 / 成本更低 / 延迟更小。
如果展开讲，核心机制是……
但它也有边界，比如……
如果面试官愿意，我可以继续展开讲一下它和 Q 的区别。
```

## 常见错误

- 上来堆术语，没有结论
- 只背定义，不讲 trade-off
- 只能说 happy path，不会讲异常路径
- 不能把原理映射到项目场景
