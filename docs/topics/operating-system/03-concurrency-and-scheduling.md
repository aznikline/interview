# 并发与调度

## 1 分钟速答

并发题的本质是 CPU 时间如何分配、共享状态如何协调、上下文切换如何影响性能。进程、线程、协程只是抽象层不同，真正要回答的是调度成本、同步成本和业务模型是否匹配。

## 核心机制

### 调度

- 时间片轮转强调公平
- 优先级调度强调响应
- CFS 等现代调度器强调虚拟运行时间

### 并发控制

- 互斥锁保护临界区
- 自旋锁适合短临界区
- 条件变量用于等待条件
- 原子操作和内存序适合更细粒度控制

### 性能代价

- 线程过多导致上下文切换增多
- 锁竞争导致吞吐下降
- false sharing 会引发缓存一致性开销

## 高频问法

- 线程池为什么不能无限开线程？
- 自旋锁和互斥锁怎么选？
- 协程为什么适合 I/O 密集场景？

## 深挖与误区

- 协程不是对 CPU 密集任务的银弹
- 自旋锁适用前提是临界区短且 CPU 可承受
- 调度问题要和业务工作负载一起分析
