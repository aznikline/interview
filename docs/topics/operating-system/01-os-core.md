# 操作系统核心知识

## 1 分钟速答

操作系统知识在后端面试里最重要的价值，不是考定义，而是解释并发、内存、I/O 和性能问题。你需要理解从用户态代码到内核调度、页表映射、系统调用和网络 I/O 的完整链路。

## 核心机制

### 进程与线程

- 进程是资源分配单位，线程是调度单位
- 多线程共享地址空间，但栈和寄存器上下文独立
- 线程切换和进程切换都要保存上下文，但进程切换通常更重

### 内存

- 虚拟内存让每个进程看到独立地址空间
- 页表完成虚拟地址到物理地址映射
- TLB 用于缓存地址转换结果
- 缺页中断和页替换会影响延迟

### I/O

- 阻塞 I/O 把线程卡在系统调用上
- 非阻塞 I/O + I/O 多路复用提升连接处理能力
- epoll 相对 select / poll 更适合大量连接场景

## 高频问法

- 进程和线程区别是什么？
- 为什么线程切换也很贵？
- select / poll / epoll 区别是什么？
- 用户态和内核态怎么切换？
- mmap 和 read/write 有什么区别？

## 深挖与误区

- 不要把“协程比线程轻量”说成绝对结论，仍取决于 runtime 和调度方式
- 不要把 epoll 神化，高并发场景依然可能受限于业务处理和系统资源
- 讲 OS 时最好落到真实问题：慢查询、上下文切换过多、锁竞争、page fault
