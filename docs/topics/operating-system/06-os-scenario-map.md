# 操作系统场景地图

## 1 分钟速答

操作系统题不是要你背教材，而是要你解释现象。线程切换、页缺失、epoll、零拷贝、锁竞争、false sharing、内存序，最后都会落到同一类面试问题：为什么服务慢、为什么 CPU 忙、为什么吞吐上不去、为什么恢复后还是抖。

## 核心机制

### 为什么 OS 更适合按“现象场景”来复习

如果只按概念背：

- 进程、线程、页表、TLB、epoll 各自都懂一点
- 但一到真实服务问题，比如“为什么 P99 很差”，就不知道先讲什么

如果按现象场景组织，你会更容易先抓住：

- 是调度开销问题
- 是内存层次问题
- 是 I/O 与线程模型问题
- 是锁与缓存一致性问题
- 是排障与观测问题

### 场景 1：调度与上下文切换

代表问题：

- 进程和线程有什么区别？
- 线程切换为什么贵？
- 协程为什么通常更轻？

真正要讲清的是：

- CPU 在保存和恢复什么
- cache、TLB 为什么会被打散
- 为什么线程数上去不一定吞吐就上去

### 场景 2：内存层次与尾延迟

代表问题：

- 虚拟内存解决了什么？
- page fault 为什么会导致抖动？
- TLB miss、cache miss、page fault 怎么理解？

真正要讲清的是：

- 地址空间抽象带来了什么收益
- 页缺失和访存层次为什么会放大尾延迟
- 为什么这种问题在高并发系统里更明显

### 场景 3：I/O 模型与慢请求

代表问题：

- select / poll / epoll 有什么区别？
- 为什么 epoll 适合高并发？
- 为什么 epoll 服务也会被慢请求拖垮？

真正要讲清的是：

- epoll 解决的是“谁就绪了”，不是“业务变快了”
- 慢下游、慢连接、线程池阻塞为什么仍会拖垮服务
- I/O 模型和线程模型如何配合

### 场景 4：数据搬运与零拷贝

代表问题：

- 零拷贝是什么？
- sendfile 和 mmap 有什么区别？
- 为什么零拷贝不是银弹？

真正要讲清的是：

- 哪些 copy 被减少了
- 哪些成本依然存在
- 为什么 HTTPS、压缩、业务加工会影响收益

### 场景 5：锁竞争与共享内存抖动

代表问题：

- 死锁为什么发生？
- false sharing 是什么？
- 锁竞争和 false sharing 有什么区别？

真正要讲清的是：

- 线程为什么会在共享资源上互相拖慢
- 为什么 CPU 很忙但吞吐不高
- 哪些问题是锁语义，哪些问题是 cache line 粒度

### 场景 6：内存序与并发可见性

代表问题：

- 内存屏障为什么重要？
- volatile 和原子操作是什么关系？
- happens-before 怎么理解？

真正要讲清的是：

- 编译器和 CPU 为什么会重排序
- 可见性和顺序语义为什么会影响程序正确性
- 锁和原子变量底层在保证什么

### 场景 7：观测、排障与恢复

代表问题：

- 上下文切换高先看什么？
- 慢请求、慢磁盘、慢数据库怎么区分？
- 恢复期为什么仍会抖？

真正要讲清的是：

- 看哪些指标
- 先怀疑哪一层
- 如何从系统现象反推到资源瓶颈

## 高频问法

- 为什么 OS 题不能只背定义？
- 为什么 page fault 会直接连到尾延迟？
- 为什么 epoll 不是高并发银弹？
- 为什么 false sharing 会让 CPU 忙但吞吐不高？
- 为什么 OS 题最后总会落到指标和排障？

## 深挖与误区

- 不要只会讲“协程更轻量”，要讲轻在哪里
- 不要把内核机制和后端现象割裂开
- 不要把零拷贝理解成完全零成本
