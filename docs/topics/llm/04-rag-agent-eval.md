# RAG、Agent、MCP 与评估

## 1 分钟速答

RAG、Agent、MCP 和评估这部分，真正高频的问题不是“会不会用某个框架”，而是：检索链路怎么设计、工具调用边界在哪、Agent 为什么难稳定、评估怎么做闭环。

## 核心机制

### RAG 主线

- chunking、embedding、召回、重排、答案生成
- 两阶段检索、多路召回、ReRank
- 检索质量、时效性、上下文预算

### Agent / MCP 主线

- 工具调用、状态管理、规划与执行
- MCP server / client 的边界
- 权限、安全、失败恢复、可观测性

### 评估主线

- 离线评测与在线评测
- 幻觉、准确率、召回、命中率、人工偏好
- 评估如何反哺 prompt、检索和模型策略

## 高频问法

- RAG 为什么不能简单理解成“接个向量库”？
- ReRank 的价值是什么？
- Agent 为什么难稳定？
- MCP 在解决什么工程问题？
- 幻觉怎么评估和缓解？

## 深挖与误区

- 不要把 RAG 讲成单步流程图，不讲召回质量和重排
- 不要把 Agent 讲成“模型自己会规划”，忽略状态和工具边界
- 不要把评估讲成一个分数，忽略场景指标和闭环动作
