# LLM 基础与术语

## 1 分钟速答

LLM 基础不是在背历史，而是在建立一套统一语言。你至少要能讲清：token、embedding、上下文窗口、预训练、SFT、对齐、推理、幻觉、RAG、Agent，这些词各自处在整条链路的什么位置。

## 核心机制

### 基础概念主线

- token 和 tokenizer 决定输入粒度与成本
- embedding 把离散 token 映射到连续空间
- 预训练负责学习通用语言建模能力
- SFT 和对齐负责把模型往“更像助手”的方向推
- 推理负责把训练好的模型稳定地跑在真实服务里

### 为什么 decoder-only 成为主流

- 自回归生成更自然适配对话和生成场景
- 训练目标统一，工程生态成熟
- 推理和缓存优化路径清晰

### 你必须能区分的几个层次

- 语言模型能力 vs 指令跟随能力
- 训练优化 vs 推理优化
- 模型能力不足 vs 检索 / 工具 / 系统工程不足

## 高频问法

- token 和参数量是什么关系？
- decoder-only 为什么更适合 LLM？
- 上下文窗口变长为什么不等于模型更聪明？
- 幻觉为什么不是单一原因？

## 深挖与误区

- 不要把“模型大”直接等价成“能力强”
- 不要把 prompt 技巧当作模型本身能力
- 不要把所有错误都归到幻觉，很多其实是检索和系统工程问题
