# LLM 架构与训练

## 1 分钟速答

LLM 架构与训练面试，核心不在于把 Transformer 每层公式背一遍，而在于解释：为什么这样设计、训练代价是什么、并行化怎么做、SFT/RLHF/DPO 分别在补什么。

## 核心机制

### 架构高频点

- attention、位置编码、layer norm、激活函数
- MHA / MQA / GQA 的取舍
- MoE 在参数量、激活成本和工程复杂度之间的平衡

### 训练高频点

- 数据清洗、tokenizer、数据配比
- 数据并行、张量并行、流水线并行、序列并行
- 梯度累积、显存优化、checkpointing

### 对齐高频点

- SFT：让模型学会更像目标输出
- RLHF：把偏好信号引入训练
- DPO：在不显式训练 reward model 的情况下做偏好优化

## 高频问法

- MHA、MQA、GQA 怎么选？
- 为什么训练大模型需要多维并行？
- RLHF 和 DPO 各自解决什么问题？
- 为什么数据质量经常比花哨技巧更重要？

## 深挖与误区

- 不要只会背并行名词，不会讲通信和显存代价
- 不要把 SFT、RLHF、DPO 混成一个大概念
- 不要只讲模型结构，不讲训练约束和工程复杂度
