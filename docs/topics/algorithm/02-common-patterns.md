# 高频算法模式

## 1 分钟速答

算法准备最有效的方法不是一题一题背，而是把高频题归到少数模式里：滑窗、双指针、DFS/BFS、二分、回溯、堆、并查集、动态规划。真正决定表现的是你能不能在 1 分钟内识别模式并说出关键不变量。

## 核心机制

### 模式到信号

- `连续子数组 / 子串` -> 滑窗、前缀和
- `有序数组 / 单调性` -> 二分
- `连通块 / 最短步数` -> BFS
- `枚举组合 / 排列 / 子集` -> 回溯
- `top k / 实时最值` -> 堆
- `集合合并 / 连通性` -> 并查集

### 回答模板

- 先识别题型
- 再给状态或不变量
- 然后说明推进方式
- 最后讲复杂度与边界

## 高频问法

- 为什么岛屿问题常用 DFS/BFS？
- 什么时候是“二分答案”而不是普通二分？
- top k 为什么不用全排序？
- 并查集为什么近似 O(1)？

## 深挖与误区

- 不要把“会写代码”等同于“会面试表达”
- 滑窗的关键不在双指针，而在窗口约束
- BFS/DFS 的区别要回到“层次最短路径”和“深度遍历”本质
