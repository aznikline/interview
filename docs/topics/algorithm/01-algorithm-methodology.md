# 算法题方法论

## 1 分钟速答

算法面试考察的不是你背了多少题，而是你能否快速识别题型、建立状态或不变量、控制边界条件，并把思路清晰说出来。高频题的核心是模板化识别，不是题海战术。

## 核心机制

### 识别框架

- 数组区间问题：优先想双指针、滑动窗口、前缀和
- 搜索问题：优先想 DFS、BFS、回溯
- 有序问题：优先想二分
- 最优子结构问题：优先想 DP
- 动态连通性：优先想并查集

### 输出框架

- 先定义状态或不变量
- 再说明转移或推进逻辑
- 然后处理边界条件
- 最后分析复杂度

## 高频问法

- 最长无重复子串为什么想到滑窗？
- 岛屿类问题什么时候 BFS，什么时候 DFS？
- 二分答案和普通二分区别是什么？
- 动态规划如何从暴力搜索推导出来？

## 深挖与误区

- 不要一上来写代码，先说解法类别和复杂度
- 不要把回溯和 DFS 混成一个概念，前者强调枚举决策树
- 动态规划最容易错的是状态定义和初始化
