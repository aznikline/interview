# 算法专题首页

## 1 分钟速答

算法准备的目标不是“刷过多少题”，而是“看到题能识别模式，开口能说出思路，落笔不乱边界”。高频面试题最终都能回收到少数模板和框架。

## 核心机制

### 推荐学习顺序

1. 方法论
2. 高频模式识别
3. 框架、例题和训练法
4. 核心题清单
5. 每日口述与白板练习

### 学完这一组内容后应该具备什么能力

- 能识别常见模式属于哪一类框架
- 能在写代码前先口述思路和复杂度
- 能指出边界条件和常见坑

## 高频问法

- 什么问题适合滑动窗口？
- 双指针和滑动窗口怎么区分？
- DP 怎么从暴力推到状态转移？
- 状态设计为什么是 DP 的核心？
- BFS、DFS、回溯分别什么时候用？

## 深挖与误区

- 不要只背代码模板
- 不要只会做，不会讲
- 不要忽略复杂度和边界条件
