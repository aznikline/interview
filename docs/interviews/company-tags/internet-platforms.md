# 互联网大厂面试关注点

## 阿里 / 腾讯 / 字节 / 美团这类平台型后端

重点通常不是单点知识，而是：

- 高并发链路是否讲得透
- 缓存、一致性、MQ、限流是否能讲 trade-off
- 项目是否能讲出指标、容量、故障、复盘
- 系统设计能否从需求澄清走到落地

## 回答风格建议

- 少讲术语堆砌，多讲约束和指标
- 少说“用了什么”，多说“为什么这样选”
- 每个方案最好补一句代价和失败场景
