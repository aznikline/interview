## 学完一篇文档后，最低输出标准

- 能用 `1 分钟` 讲清这篇文档在回答什么问题
- 能口述 `3 个高频问法`
- 能讲出 `1 个追问`
- 能把这个知识点连到 `项目 / 系统设计 / 性能指标`
