# 总路线图

这份路线图不再只是“主题罗列”，而是和 [Interview University 学习计划](../../tracks/interview-university/README.md) 对齐的阶段图。

## 适用岗位

- 通用后端开发
- 中高级后端 / 基础架构 / 分布式
- 搜索推荐 / 广告后端
- AI Infra / 推理引擎 / 编译器工程

## 总体学习顺序

### Phase 0: Before You Start

- 选目标岗位
- 选主语言
- 设时间预算
- 建弱项清单

### Phase 1: Backend Core

- 数据库
- 缓存
- 消息队列
- 一致性与高并发

### Phase 2: Algorithms and Data Structures

- 模式识别
- 复杂度与边界
- 高频题训练

### Phase 3: Operating Systems and Concurrency

- 进程线程
- 内存
- I/O
- 调度与锁

### Phase 4: System Design

- 拆题
- 估算
- 架构
- trade-off
- 故障处理

### Phase 5: AI Compiler and AI Infra

- IR
- lowering
- fusion
- runtime
- 指标与项目表达

### Phase 6: Final Review

- mock
- 项目表达
- 弱项清单
- 最后冲刺

## 时间分配建议

- 后端主链路：30%
- 算法：20%
- 操作系统：15%
- 系统设计：20%
- AI 编译器：15%

如果你的目标是 AI Infra / 编译器工程，可以把 AI 编译器提升到 `20%-25%`。

## 不同人群的重点

### 校招 / 基础薄弱

- 后端主链路
- 算法
- OS
- 基础系统设计

### 社招后端

- 后端主链路
- 系统设计
- OS 与并发
- 项目表达

### AI Infra / AI 编译器

- 后端与系统设计主链路不能丢
- AI 编译器专题必须做到差异化
- runtime 与在线服务视角必须补上
