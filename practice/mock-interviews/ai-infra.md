# Mock 2：AI Infra / AI 编译器

## 场景设定

候选人目标岗位为 AI 编译器或推理优化工程师。

## 问题序列

1. 介绍你理解的 AI 编译器链路。
2. 算子融合为什么能提速？
3. MLIR、XLA、TVM、Triton 有什么差别？
4. 动态 shape 为什么难优化？
5. LLM 推理中的主要瓶颈是什么？
6. 如果线上延迟突然抖动，你会怎么排查？

## 追问脚本

- 哪些优化更偏编译器，哪些更偏 runtime？
- 为什么有些融合会降低 occupancy？
- batch size、latency、throughput 之间如何平衡？

## 评分维度

- 是否理解层级边界
- 是否能把编译优化和硬件行为连起来
- 是否能用系统视角解释性能现象

## 参考答案

回答时优先沿着：

- 图层
- kernel 层
- runtime 层
- device 层

四层去组织，不要只背框架名。
