# 算法模式压测包

适合：

- 模式平时看得懂，但面试里一换皮就乱
- 第一问能答，追问一来就不知道该坚持原模式还是换模式
- 想专门训练“算法题被追问时怎么稳住”

## 使用方法

- 每次只练一个主模式
- 主问题答 `1` 分钟，再接 `3` 轮追问
- 每轮都必须回到 `模式 / 不变量 / 边界 / 复杂度`

## Section 1：滑动窗口 vs 前缀和

### 主问题

为什么这题是滑动窗口，而不是前缀和？

### 第一轮追问

- 你的窗口合法性怎么定义？
- 左指针什么时候动？
- 为什么窗口条件是单调的？

### 第二轮追问

- 如果要求的是“和等于 k”，为什么很多时候滑窗不稳？
- 什么情况下更适合前缀和 + 哈希？
- 如果数组有负数，滑窗为什么容易失效？

### 第三轮追问

- 最短覆盖子串为什么比普通窗口题更难？
- 如果面试官把条件改成“至多 k 个不同字符”，你怎么改？
- 如果你现场卡住，怎么保分？

## Section 2：DFS / BFS / 回溯

### 主问题

为什么这题要用回溯，而不是普通 DFS 或 BFS？

### 第一轮追问

- 你的路径状态是什么？
- 选择列表是什么？
- 撤销选择发生在哪里？

### 第二轮追问

- 如果只求最短步数，为什么 BFS 更自然？
- 如果只求连通性，为什么普通 DFS 就够了？
- 剪枝条件应该放在哪？

### 第三轮追问

- 如果结果集很大，怎么降低无效搜索？
- 如果面试官要求去重，你先改什么？
- 你怎么一句话区分 DFS 和回溯？

## Section 3：二分搜索

### 主问题

为什么这是二分答案，而不是普通二分？

### 第一轮追问

- 单调性在哪里？
- 左边界和右边界是什么？
- `mid` 判定函数怎么写？

### 第二轮追问

- 为什么答案空间不是数组下标？
- 为什么这题不能直接贪心？
- 什么时候二分答案会很危险？

### 第三轮追问

- 如果判定函数本身很贵怎么办？
- 如果区间上界不好找怎么办？
- 面试官追问边界死循环时你怎么解释？

## Section 4：DP 状态设计

### 主问题

为什么这个状态定义是对的？

### 第一轮追问

- 这个状态表示什么子问题？
- 为什么它不会漏情况？
- 初始化怎么定义？

### 第二轮追问

- 还能换一种状态吗？
- 如果状态更细或更粗，会出什么问题？
- 什么时候能压缩空间？

### 第三轮追问

- 为什么这题不是贪心？
- 为什么 LIS 还能做到 `O(n log n)`？
- 如果你现场想不到最优解，怎么先拿基础分？

## Section 5：图 / 并查集

### 主问题

为什么这里更适合并查集，而不是 DFS / BFS？

### 第一轮追问

- 你要解决的是连通性还是路径问题？
- 合并操作的价值在哪里？
- 路径压缩为什么有效？

### 第二轮追问

- 如果是动态加边，为什么并查集更方便？
- 如果要删除边，并查集为什么不一定好用？
- 如果是最短路问题，为什么并查集不合适？

### 第三轮追问

- 面试官改成拓扑排序题时，你怎么快速切模式？
- 如果题目既有连通性又有顺序依赖，先看哪层？
- 怎么一句话说清并查集的使用边界？

## 复盘问题

- 我最容易在哪个模式切换点答散？
- 我有没有被追问后忘掉原始主问题？
- 我是不是只会报模板，不会解释为什么适合？
- 下一轮应该补哪一组代表题？
