# LLM 压测包

适合：

- LLM 题会背，但一追问就散
- 概念知道，却讲不成链路
- 想把训练、推理、RAG、Agent 的追问练稳

## 使用方法

- 每次只选 `1` 个主问题
- 主问题答 `1-2` 分钟，再接 `3` 轮追问
- 每轮都回到 `层次边界 / 核心瓶颈 / 指标 / trade-off`

## Section 1：架构与训练

### 主问题

### 第一轮追问

- encoder-decoder 为什么不占主流？
- 长上下文代价在哪里？
- 为什么训练目标更统一？

### 第二轮追问

- MHA、MQA、GQA 怎么选？
- 为什么并行训练复杂？
- 数据质量为什么比堆参数更重要？

### 第三轮追问

- 如果面试官追问到 SFT、RLHF、DPO，你怎么切层次？
- 如果让你讲训练代价，你先讲显存还是通信？
- 你怎么一句话解释“架构选择和推理优化是连着的”？
